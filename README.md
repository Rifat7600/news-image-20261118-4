An infographic timeline summing up the world news of Wednesday 18 November 2026 in one 1024x1024 image: nine stories down a central timeline — the US strike on Qeshm Island, Iran's drone attack on the US base in Kuwait, the Putin–Xi meeting in Shenzhen, the Quad meeting in Manila, Israel's Gaza operation, Cyclone Akvan, the near-done India–US trade deal, the US losing measles-free status, and the GTA VI launch — plus a footer strip with the Papua New Guinea quake, the Siberia plane crash, and Mary Peltola's Alaska Senate win.

## Files

- `entry.png` — the finished image (1024x1024, under 1 MiB)
- `generate.py` — the Pillow script that draws `entry.png` from scratch (run it here; the grader never runs it)
- `main.py` — the entry program: copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`

## Run it

```sh
python3 generate.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
